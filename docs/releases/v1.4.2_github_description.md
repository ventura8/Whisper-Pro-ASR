# Release v1.4.2 - SonarQube Cloud Findings Resolved

A maintenance release. v1.4.1 wired SonarQube Cloud into the pipeline; this one works
through what it found -- roughly 660 findings across the Python modules, the scripts, the
dashboard and the tests -- and leaves the quality gate passing with no open issues on new
code. The API contract, the decoding path and the language handling are unchanged.

---

## Highlights

### Python

- Deliberately broad exception handlers catch through a per-module `_ANY_EXCEPTION`
  constant; error handlers log with `logger.exception`, so the traceback is kept.
- Cognitive complexity was split in the INTEL-WHISPER chunk loop, the audio-separator ONNX
  patch and `create_app`, without changing what they do.
- `process_exec` applies its deadline with `asyncio.wait_for` around the whole coroutine;
  the coroutine terminates its child process on that cancellation before propagating, as
  it did before -- the timeout is now handled in one place instead of in each runner.
- Paths taken from CLI arguments or manifest data in the audio-matrix tooling are confined
  to their work directory.
- The ASR task-start log line carries only the normalized format and a
  control-character-free language.

### Shell and PowerShell

`[[ ]]` conditionals, errors to stderr, a default branch on every `case`, explicit function
returns, and the `Show-` verb for PowerShell helpers that write to the host.

### Dashboard

Shared, reassigned dashboard state lives on `globalThis` (declared in `core/state.js`)
instead of implicit globals; unit-index parsing is linear-time; five dark-theme backgrounds
now meet WCAG AA contrast.

### Tests

Module state is changed with `monkeypatch` rather than by manual assignment and restore;
composite asserts are split; each `pytest.raises` holds one raising call.

The conventions that keep the tree free of these findings are recorded in
`.agent/skills/quality/ci_quality_gates_skill.md`.

## Hardware Validation

The accuracy suite was driven with real speech on an Intel NUC (INTEL-WHISPER on the iGPU,
vocal isolation on the NPU) and on an RTX 3080 (FASTER-WHISPER with isolation, and
WHISPERX), 9/9 on each, with per-request device evidence. Details and what was not run on
silicon: `docs/validation/v1.4.2/README.md`.
